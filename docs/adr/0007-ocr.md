# ADR 0007 — OCR: Tesseract via Docling, only when a page has no text layer, gated by engine confidence

**Context.** Scanned and mixed PDFs must not be silently lost; OCR output must not be indexed when unreliable.

**Evidence (synthetic scans of an open paper; ground truth = the digital text; `eval/results/lab/ocr-eval.jsonl`, regenerate with `scripts/lab/ocr-eval.mts`).**
| scan | word recall / precision | Tesseract mean confidence | gate |
|---|---|---|---|
| clean 200 dpi | 94–99 % / 89–98 % | 91–94 | indexed |
| rotated (2.5° skew, 90°) | 94–99.7 % / 96–98 % | 91 | indexed |
| degraded (100 dpi, blur, noise, JPEG 35) | 0–17 % / 0–12 % | 31–34 | **excluded + reported** |
| mixed (2 digital + 1 scanned) | 96–99.5 % all pages | 94 (scanned page only) | indexed; digital pages not re-OCR'd |

A text-shape readability heuristic was tried first and **failed** (garbage OCR scored 0.60–0.71 "word-like"), so the gate uses the OCR engine's own word confidence (threshold 60).

**Decision.** OCR only pages with < 25 programmatic characters (`--ocr auto`); notes are always OCR'd. OCR text is stored as `content_type = ocr_text` (or `handwritten_note`), `derivation = ocr`, with page confidence; the UI shows "Scanned page (OCR) · N % confidence".

**Alternatives.** EasyOCR / RapidOCR (larger models), Apple Vision OCR (`OcrMacOptions`, macOS-only → not deployable), cloud OCR (paid). Handwriting: Tesseract is weak on handwriting; a vision LLM is the fallback (quota-limited) — evaluated only with real user photos.

**Reconsider when** handwriting accuracy on real notes is measured and found insufficient.
